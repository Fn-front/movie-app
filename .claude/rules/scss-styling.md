# スタイリングルール（SCSS Modules）

## 【必須】基本ルール

- SCSS Modules を使用する
- HTML要素を直接スタイリングしない（独自クラス名必須）
- クラス名にHTMLタグ名を使用するのは問題ないが、セレクタでHTMLタグを直接指定しない
- デザインシステム変数を使用する（カラー・スペーシング等のハードコード禁止）

## 【必須】アニメーション

- アニメーションは最小限に抑える（opacity / transform 程度）
